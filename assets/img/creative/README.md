# assets/img/creative/

Simpan karya fotografi, videografi (thumbnail), dan desain di sini.

Untuk menampilkannya, buka `script.js`, cari array `creativeWorks`, lalu
ubah nilai `image: null` menjadi `image: "assets/img/creative/nama-file.jpg"`
pada item terkait. Setiap item juga punya `category` ("photography",
"videography", atau "design") yang menentukan filter galeri.
