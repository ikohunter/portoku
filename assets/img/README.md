# Folder assets/img/

- `profile.jpg` — foto profil untuk hero section.
  Cukup letakkan file dengan nama persis `profile.jpg` di folder ini.
  Foto akan tampil **otomatis** menggantikan placeholder inisial "HL" —
  tidak perlu mengedit index.html/CSS/JS sama sekali. Pastikan nama file
  dan ekstensinya persis `profile.jpg` (huruf kecil semua); jika nama
  berbeda (mis. `Profile.JPG` atau `.png`), foto tidak akan terdeteksi.

- `og-cover.jpg` — gambar sampul untuk preview saat link dibagikan
  (ukuran disarankan 1200x630px). Setelah tersedia, aktifkan kembali baris
  `<meta property="og:image" ...>` yang saat ini dikomentari di `<head>`
  pada `index.html`.

- `projects/` — thumbnail untuk setiap kartu proyek.
- `creative/` — foto/desain untuk galeri Creative Works.
